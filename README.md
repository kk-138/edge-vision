# 安心看護 — UI/UX 互動原型（程式碼版）

純 HTML / CSS / JS 寫成，**不需要安裝任何套件或建置工具**，用瀏覽器直接開啟 `index.html` 即可操作。

## 如何使用

1. 用 VS Code 開啟 `care-cam-app` 資料夾
2. 建議安裝 VS Code 擴充套件 **Live Server**，在 `index.html` 上按右鍵 → `Open with Live Server`
   （也可以不裝任何套件，直接雙擊 `index.html` 用瀏覽器打開，但部分瀏覽器對 `file://` 開啟本地字型/資源可能有限制，用 Live Server 體驗最完整）

## 修改指南

- **改配色 / 字體**：只改 `css/design-system.css` 的 `:root` CSS 變數，全站會一起變。
- **改假資料**：每個頁面底部 `<script>` 內都有寫死的陣列（如 `CAMERAS`、`NOTIFS`），直接改陣列內容即可換成你要的情境資料。
- **三級警報倒數秒數**：`09-三級警報機制.html` 內為了展示方便設為 10 秒，正式版請改回 `duration: 30`。
- **新增頁面**：複製任一支 html，改 `<body data-nav-active="XX">` 對應的編號，並到 `js/shared.js` 的 `NAV_ITEMS` 陣列加入該頁連結，導覽列會自動出現。

## 目前為靜態原型，尚未串接

- 攝影機畫面為色塊佔位，未接真實串流
- 跌倒/越界等偵測皆為手動按鈕模擬觸發，未接 AI 模型
- 撥號、LINE/SMS 發送為畫面模擬，未串接電信/通訊 API
- 資料皆為前端寫死的假資料，未接後端 API / 資料庫

這些留白處都已在對應頁面的 JS 中用清楚的變數/函式命名標出，方便你之後接上真實資料或串接後端。
